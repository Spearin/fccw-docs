# Introduction to Tutorials

The **FM03A Tutorial Operations: Basic** is designed to guide new and returning players in mastering Flashpoint Campaigns Cold War (FCCW). This manual provides clear, step-by-step instructions, practical examples, and detailed explanations to introduce fundamental gameplay mechanics. Organized in an accessible, progressive format, this resource helps beginners understand how to effectively command units, leverage terrain, coordinate combined arms operations, and execute sophisticated tactical maneuvers in authentic Cold War battlefield scenarios.

These tutorials emphasize simplicity, clarity, and hands-on learning to help new players build confidence and proficiency in managing complex military engagements swiftly.

## Overview of Tutorials:

This chapter introduces you to hands-on tutorials designed to help you learn the basics of key battlefield operations. Whether you're new to tactical games or need a refresher, these tutorials will guide you step-by-step through realistic scenarios, allowing you to build confidence and sharpen your skills.

- [**Tutorial
- User Interface Layout**](#_User_Interface_Layout)  
Learn the layout of the game’s interface and the functions of several useful overlays and dialogs to help with your planning and battle.

- [**Tutorial - Standard Operating Procedure (SOP)**](#_Issuing_Orders_to) Learn how to set and adjust the Standard Operation Procedures (SOPs) for your units to make them fight and survive on the battlefield.

- [**Tutorial - Issuing Orders To Units**](#_Issuing_Orders_to_1) Learn how to issue orders to move units, call in support strikes, and rest and refit your force.

- [**Tutorial - Command and Control**](#_Standard_Operating_Procedure) Learn how the chain of command and condition of your units impacts orders delay and other functions.

- [**Tutorial
- End Game Post-Mortem**](#_End_Game_Post-Mortem_1)  
Learn how review the various dialogs that explain the end of game scoring and resulting losses and expenditures of both forces.

Each tutorial is carefully crafted with new players in mind, offering clear instructions and helpful tips to help you get up to speed quickly. These tutorials will prepare you to undertake more advanced actions and make informed tactical decisions in the field.

## A Quick Start Tutorial

The Basic Operations Tutorial scenario is used for all the sections of this guide. It is a simple mission you can execute to learn the basic game mechanics of the game engine and functions as a Quick Start and introduction to Cold War.

**NOTE:** More information and details for all the games functions can be found in ***FM01 Game Operations***. We strongly urge new players to skim this document to gain an understanding of all the tools available.
