# Advanced Tutorial Overview

## Simple or Detailed Operation Versions

Each of the tutorials in the Advanced FM has two playthroughs of the same scenario. The first is a simplified run of all the steps to perform the operation. This should be done with the Recruit difficulty setting so the enemy units are visible to aid in performing the steps. The second is a more detailed run of the operation with more information and emphasis on the operation versus the enemy. You should look over both and use them to become familiar with these new game capabilities.
