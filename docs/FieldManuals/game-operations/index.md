# :material-book-open-variant-outline: FM01 Game Operations Overview

<div class="grid cards" markdown>

-   :material-monitor-dashboard:{ .lg .middle } [**Main Menu**](main-menu)

    ---

    The Main Menu has all the buttons to start new games, resume a game in play, or jump into one of the edit functions to create game content.

-   :material-menu-open:{ .lg .middle } [**User Preferences**](user-preferences)

    ---

    These settings can be changed at any time via this button on the Welcome Commander Screen, in-game from the Menu Bar, or hitting F2.

-   :fontawesome-solid-flag:{ .lg .middle } [**Core Game Panels**](core-game-panels)

    ---

    Next to the map are the Core Game Panels. The default location of these panels is positioned along the right edge of the screen but can be moved anywhere on screen.

-   :material-earth-box:{ .lg .middle } [**The Game Map**](the-game-map)

    ---

    All action in the game takes place on beautifully rendered maps of real-world terrain.

-   :black_large_square:{ .lg .middle } [**Unit Counters**](unit-counters)

    ---

    Units are the individual playing pieces in the game, composed of one or more subunits such as vehicles, aircraft, artillery pieces, or squads of people.

-   :fontawesome-solid-person-military-pointing:{ .lg .middle } [**Issuing Orders**](issuing-orders)

    ---

    Control your forces by giving orders to your units.

-   :material-arrow-decision:{ .lg .middle } [**Plotting Movement and Fires**](plotting-movement-and-fires)

    ---

    Learn how to move your units, issue orders, adjust and change Movement types along the path, and issue artillery and air strikes on target locations.

-   :octicons-checklist-24:{ .lg .middle } [**Standard Operating Procedures (SOP)**](standard-operating-procedures-sop)

    ---

    Learn how to set and adjust the Standard Operation Procedures (SOPs) for your units to make them fight and survive on the battlefield.

-   :fontawesome-solid-explosion:{ .lg .middle } [**Combat Operations**](combat-operations)

    ---

    Combat is the very focus of this game and is detailed in this section.

-   :material-medal:{ .lg .middle } [**Victory Conditions and End Game**](victory-conditions-and-end-game)

    ---

    Learn how the victory conditions are calculated.
