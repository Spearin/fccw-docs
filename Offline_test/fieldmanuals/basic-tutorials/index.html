    1. Basic Tutorial Overview

    • User Interface Layout

      Learn the layout of the game’s interface and the functions of several useful overlays and dialogs to help with your planning and battle.

    • Standard Operating Procedure (SOP)

      Learn how to set and adjust the Standard Operation Procedures (SOPs) for your units to make them fight and survive on the battlefield.

    • Issuing Orders To Units

      Learn how to issue orders to move units, call in support strikes, and rest and refit your force.

    • Command and Control

      Learn how the chain of command and condition of your units impacts orders delay and other functions.

    • Resolving the Battle

      Turn by turn through the tutorial.

    • End Game Post-Mortem

      Learn how review the various dialogs that explain the end of game scoring and resulting losses and expenditures of both forces.
